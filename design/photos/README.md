# عکس محصول‌ها

عکس هر محصول را با همین نام‌ها اینجا بگذار (jpg، png یا webp — فرقی نمی‌کند):

| فایل | محصول |
| --- | --- |
| `redkey-w12` | جارو شارژی سه‌کاره ردکی |
| `fasdunt-hv1` | جارو شارژی آب و خاک فستدانت |
| `kochwerk-af90` | سرخ‌کن بدون روغن کوخورک ۷ لیتری |
| `dassler-pro2400` | سشوار حرفه‌ای داسلر ۲۴۰۰ وات |

بعد از گذاشتن عکس‌ها:

```bash
node scripts/embed-photos.mjs
```

عکس داخل خود صفحه نوشته می‌شود تا `wanko-home.html` یک فایل مستقل بماند.
هر عکسی که نگذاری، طرح خطی همان محصول سر جایش می‌ماند؛ اگر بعداً فایلی را
پاک کنی و دوباره اسکریپت را بزنی، عکس از صفحه هم برداشته می‌شود.

بهترین نتیجه با عکس مربعی روی زمینهٔ سفید یا شفاف، دست‌کم ۹۰۰ در ۹۰۰ پیکسل.
