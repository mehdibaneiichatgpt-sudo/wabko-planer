# طراحی صفحهٔ اول wanko.ir

`wanko-home.html` یک صفحهٔ کامل و مستقل است: بدون فریم‌ورک، بدون تصویر خارجی،
بدون بیلد. کافی است در مرورگر بازش کنی.

## هستهٔ صفحه: استعلام سریال

هیرو یک ترمینال کارکردی است، نه تصویر. سریال را می‌زنی (رقم فارسی و بدون خط
تیره هم قبول است) و پلاک مشخصات همان دستگاه خوانده می‌شود. الان روی یک دفتر
نمونهٔ چهارتایی داخل همان فایل کار می‌کند؛ برای سایت واقعی فقط باید `BOOK`
به API انبار وصل شود. کد ناشناس صادقانه «ثبت نشده» می‌گیرد، نه تیک سبز.

## موشن

- ورود صفحه: تیتر خط‌به‌خط از پشت ماسک بالا می‌آید، دستگاه با stroke کشیده
  می‌شود، پلاک می‌نشیند، نوار تضمین‌ها یکی‌یکی روشن می‌شود
- استعلام: پویش نور روی پلاک، سپس رمزگشایی نویسه‌به‌نویسهٔ هر فیلد؛ کد ناشناس
  یک تکان کوتاه می‌خورد
- نور مورب روی بدنهٔ فلزی هیرو که دنبال نشانگر می‌آید
- کارت محصول با هاور یا فوکوس صفحه‌کلید می‌چرخد و پلاک مشخصاتش را نشان می‌دهد
- ریل «مسیر کالا» با اسکرول کشیده می‌شود (`animation-timeline: view()`؛ جایی
  که پشتیبانی نشود، کامل و ساکن دیده می‌شود)
- همهٔ این‌ها با `prefers-reduced-motion` خاموش می‌شوند و هیچ متنی پشت
  انیمیشن پنهان نمی‌ماند

## نکته‌ها

- راست‌به‌چپ، فارسی، با حالت روشن و تاریک (دکمهٔ ماه در هدر)
- قیمت‌ها و تعداد محصول‌ها جای‌نگهدارند و باید به داده واقعی وصل شوند
- تصویرهای خطی جای عکس واقعی محصول‌اند
- تنها منبع بیرونی، فونت‌های گوگل است؛ برای سایت واقعی بهتر است فونت‌ها روی
  همان دامنه میزبانی و به فارسی سابست شوند
